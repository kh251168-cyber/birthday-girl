BIRTHDAY BESTIE WEBSITE ♡

Files:
- index.html       = Page 1 (welcome)
- surprise.html    = Page 2 (heart-collecting mini game + birthday reveal)
- style.css        = all styling
- script.js        = interactions
- assets/          = character images

How to open:
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge, or another browser.
3. Click "Open your surprise".
4. On page 2, tap all three hearts, then open the gift.

How to personalize:
- In surprise.html, edit the birthday message inside the section with class="letter".
- Replace the text "my favorite human" in index.html if you want to add her name.
- Replace the two character images in assets/ with your own images, keeping the same filenames.
- You can edit colors at the top of style.css under :root.

Note: Google Fonts need an internet connection; the site still works without them using fallback fonts.
